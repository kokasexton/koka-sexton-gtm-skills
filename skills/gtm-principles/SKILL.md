These principles are `KOKA.md` turned into decision rules. If anything in this library conflicts with them, they win.

# GTM Principles

| Principle | Decision rule | Applied in |
|---|---|---|
| **Signal over vanity** | Report who engaged, how senior, from which account. Never lead with impressions. | `skills/warm-list`, `skills/ads-measurement` |
| **Evidence over opinion** | Every number cites a source; otherwise it's labelled an estimate. | `skills/linkedin-algorithm`, the data-accuracy test |
| **Systems over hacks** | Design the loop before producing the output. One good post is luck. | `skills/content-engineer` |
| **Fewer, better** | 3–5 posts a week; a few motions done well; tier-1 accounts you can actually research. | `skills/post-scheduling`, `skills/qualify-accounts` |
| **Comments are the CRM** | Reply to every comment. Treat the thread like pipeline. | `skills/post-engagement` |
| **Behaviour over labels** | Target what people do, not what they call themselves. Classify off their own headline. | `skills/warm-list`, `skills/content-engagement` |
| **Signal beats list size** | 10 warm, ICP-fit people outperform 1,000 cold records. | `skills/list-building` |
| **One change at a time** | Change one lever, measure, then change the next. | `skills/ads-optimization`, `skills/subject-lines` |
| **Never fabricate** | No made-up stats, sources, or familiarity. | `skills/personalization-qa` |
| **Human gate** | Nothing outbound sends without a person reading it. | Every outreach skill |

## Using them in a debate

1. Name the decision.
2. Find the principle it touches.
3. Apply the decision rule.
4. If two principles conflict, **evidence over opinion** breaks the tie. Run the test.
