# Repurposing

Repurpose what earned **signal**: substantive ICP comments, saves, DMs, or meetings. Not what earned likes.

## One idea, many native shapes

| Source | Becomes | Note |
|---|---|---|
| Winning text post | **Document carousel**: one step per slide | Documents earn a high comment share (21.7%) |
| Winning post | **Image** with the key number or framework | Image median 70 vs link 25 |
| Document | **Short video**: you explaining the top slide | Subtitles; one idea |
| A month of winners | **Newsletter** issue | Deeper, with links (links are fine off-feed) |
| Winning post | **Thought Leader Ad** | See `skills/ads-creative` |
| Recurring question | **Citable page** with a definition, steps, and FAQ | See `skills/ai-search-visibility` |
| Sales call insight | Post → document → page | Real voice of the customer |

## Rules

- **Rewrite for the format.** A carousel is not a post pasted onto slides.
- **Leave space between reposts of the same idea**, and change the angle each time.
- **No link dumps.** "New blog post: [link]" is a link post (median 25). Teach the idea natively; link in the comments.
- Keep a **winners log**: idea, format, date, ICP comments, and what it became.
