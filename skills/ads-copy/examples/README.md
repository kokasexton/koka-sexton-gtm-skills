# Ads copy — worked example

`before.txt` is the generic ad: superlatives, jargon, no customer words and a vague "Learn more". `after.txt` follows the skill: the hook is a customer's phrase (from a call, per the voice-of-customer bank), one sentence explains why, and one specific low-friction offer closes it. `variants.txt` changes only the hook, so a result means something.

The quote, role and offer are illustrative, and no statistics are used.
