# ATL messaging — worked example

`before.txt` is the vendor-style email an executive deletes (pitch-first, 30-minute ask, slop). `after.txt` follows the skill: an observation at their altitude, one sourced number (the 26% commenter-seniority figure is from the LinkedIn Algorithm Report, see `skills/linkedin-algorithm`), and one opinion ask, under 80 words.

The names, post and comment count are illustrative. Run both through the linter: `node skills/cold-email/scripts/lint-email.mjs skills/atl-messaging/examples/after.txt`.
