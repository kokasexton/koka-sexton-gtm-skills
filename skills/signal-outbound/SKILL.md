# Signal Outbound

A list ages; a signal is current. Rank by signals, then write to the signal.

## Score

For each target, combine:
- **Engagement** — did they engage, how recently, how deeply (comment > like)?
- **ICP fit** — title, company, industry, region.
- **Fit × recency × depth** → a priority tier (P0–P3). Never sequence a P3.

## Pick the play

- **Deep commenter, ICP fit** → warm DM referencing the exact exchange.
- **Repeat engager (regular)** → name the pattern; they'll recognise it.
- **Account cluster (many engagers at one company)** → account-level play, multi-threaded.
- **Cold, high-fit, no signal** → low priority; needs a separate trigger, not a template.

## Write

- One specific observation per message — the signal itself is the personalisation.
- No fake familiarity. If you didn't read what they wrote, don't imply you did.
- Short. Give value before the ask.

## Sequence

2–3 touches, spaced, each adding something (a data point, a teardown, a relevant report). Stop on reply. Never auto-send — human gate.
