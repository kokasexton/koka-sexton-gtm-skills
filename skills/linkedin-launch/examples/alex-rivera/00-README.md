# Alex Rivera: example launch kit

Alex Rivera is a **fictional** fractional finance lead for seed and Series A founders. Nothing here is a real person, client or result. This is what a finished kit looks like, so you know what you'll get when you run `skills/linkedin-launch` on your own profile.

| File | Made by | What it is |
|---|---|---|
| `01-profile-snapshot.md` | `skills/profile-read` | The profile as it stood, word for word, plus what stands out |
| `02-positioning.md` | `skills/positioning-statement` | ICP, disqualifiers, the one-sentence position |
| `03-pillars.md` | `skills/content-pillars` | Scored topics, three pillars, editorial direction |
| `04-profile-rebuild.md` | `skills/profile-rebuild` | Headlines, About, Featured, keywords, paste-in order |
| `05-calendar.md` | `skills/content-calendar` | Thirty days on real dates (generated by the script) |
| `06-posts-review.md` | `skills/month-of-posts` | The batch check on the drafted posts |
| `07-dm-scripts.md` | `skills/dm-scripts` | Two scenarios with reply paths |

The posts themselves are in `skills/month-of-posts/examples/posts/`. The calendar and pillars input are in `skills/content-calendar/examples/`.

Where you see `[[FILL: ...]]`, the agent needed proof only the user can give. It does not guess.
