# Ads bidding — worked example

`before.txt` is the reactive setup: an inflated manual bid on a new campaign, budget split evenly across many small campaigns, and a bid raise on every cost spike. `after.txt` follows the skill: strategy chosen by situation, budget by layer and tier, fewer campaigns, and a diagnose-first order when costs spike.

No statistics are used. Cost benchmarks come from your own account history, not this repo.
