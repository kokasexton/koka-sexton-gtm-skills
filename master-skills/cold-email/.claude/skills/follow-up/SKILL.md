# Follow-up

A follow-up that says "just following up" tells them you have nothing new. Every touch has to earn its place by adding value.

## The value-rotation plan

| Touch | Angle | Example |
|---|---|---|
| 1 | The signal (see `skills/first-touch`) | "Saw your post on rebuilding the SDR team…" |
| 2 | **New evidence**: a data point or a peer pattern | "One number that surprised me: commenters were 26% more senior than likers…" |
| 3 | **A useful asset + an easy out** | "Here's the 1-page teardown either way. If it's not a priority, I'll close the loop." |

Default spacing is 3–5 business days between touches. Reply in the same thread for touch 2. Touch 3 can be a new thread with a new subject.

## Rules

- **Never repeat the pitch.** Each touch must stand on its own.
- **Shorter each time.** Touch 3 can be three lines.
- **No guilt.** Don't write "I haven't heard back" or "Did you see my last email?"
- **Stop on any reply**, including "not now". Ask when you can check back, then honour it.
- **Switch channel, not volume.** If email is quiet, a genuine comment on their post beats a fourth email (see `master-skills/linkedin`).

## Routing

- Revive later → `skills/re-engagement`
- Lint each touch → `master-skills/cold-email` (`--touch 2`, `--touch 3`)
