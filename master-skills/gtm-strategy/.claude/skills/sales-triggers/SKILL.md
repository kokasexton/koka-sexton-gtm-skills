# Sales Triggers

The trigger is the first sentence of the message. If it's specific and true, the rest of the email gets read.

## 1. Engagement (they interacted with you)

- Commented on your post → "You asked in the thread about…"
- Engaged on 3+ posts → "You've been in the comments on the last few posts about…"
- Attended or registered for your event → "You joined the session on… One thing we didn't get to…"
- Downloaded or read a resource → talk about the topic, not the download

## 2. Shared history (you have a past together)

- Former customer or user moved companies → "When you ran X at Bluepeak…"
- Past opportunity went quiet → "Last time the blocker was…" (see `skills/re-engagement`)
- Mutual connection, shared employer, same event → name it only if it's real and relevant

## 3. In market (they're researching)

- Pricing or comparison page visits from the account → write about the topic (`skills/website-visitors`)
- Comparing vendors on review sites → offer an honest comparison (`skills/competitor-signals`)
- Asked their network for recommendations → answer helpfully in public first

## 4. Symptoms (the problem is visible)

- Hiring for the job your product does → "Hiring 5 SDRs usually means…"
- Public complaint about the problem → address the problem
- A metric visibly off (slow site, broken flow, outdated content) → share the specific fix, kindly

## 5. Firmographic changes

- New leader, funding, new region, acquisition, new product → see `master-skills/signal-sourcer`

## 6. Pure fit (no trigger)

The weakest. If you use it, lead with a **genuinely useful idea**: a teardown, a benchmark from a real source, a pattern from peers. Expect lower reply rates, and aim to create warmth rather than book a meeting.

## Routing

- Score triggers together → `skills/multi-signal`
- Write the opener → `skills/first-touch`
